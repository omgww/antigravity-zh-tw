# Antigravity 繁體中文語系包

將 Antigravity 介面轉為繁體中文（Windows 10 / 11），支援 <kbd>Alt</kbd> + <kbd>Z</kbd> 即時切換中英文原文。

| 特性 | 機制說明 |
| --- | --- |
| 非侵入式掛載 | 自動備份 `app.asar` 並僅注入啟動掛鉤，不改寫官方程式本體，可隨時還原 |
| 免裝環境且輕量 | 直接使用軟體內建執行環境（無需另裝 Node.js），核心檔案合計低於 300 KB |
| 即時熱更新 | 修改 `zh-tw.json` 或翻譯引擎後存檔，已開啟的視窗立即更新，無需重啟 |
| 自動取詞與翻譯 | 內建掃描器可比對新版主程式擷取未翻譯清單，並支援自動補譯（免費介面或 Gemini API） |

## 安裝與操作

1. 前往 [Releases](https://github.com/omgww/antigravity-zh-tw/releases/latest) 下載最新 `Antigravity-zhTW-v*.zip`，解壓縮至固定資料夾（若日後搬移路徑，於新位置重跑選項 `1` 即可）。
2. 雙擊 `Antigravity-zhTW.cmd`（若跳出 Windows 保護視窗，選「其他資訊」→「仍要執行」），依選單輸入對應數字：

| 選項 | 功能 | 說明 |
| --- | --- | --- |
| `1` | 套用 / 修復中文化 | 掛載引擎並將介面轉為繁體中文 |
| `2` | 還原英文原版 | 恢復原始 `app.asar` 並停用中文化 |
| `3` | 掃描與檢查字典 | 擷取主程式尚未翻譯的詞條，並檢查 `zh-tw.json` 重複項 |
| `4` | 設定自動翻譯 | 預設關閉；開啟後於版本更新或執行 `3` 時自動補齊 `"auto"` 區段 |

## 更新與自訂字典

- **更新後自動補回**：軟體內重啟更新或關窗背景更新結束後，會自動補回繁體中文；僅手動覆蓋安裝包後需重執行一次選項 `1`。
- **修改與更新字典**：直接編輯 `zh-tw.json`，或下載最新 [`zh-tw.json`](https://raw.githubusercontent.com/omgww/antigravity-zh-tw/main/zh-tw.json)（及其他字典）覆蓋同名檔案，存檔即套用；合併外部詞條後可執行選項 `3` 檢查重複。工具包改版覆蓋資料夾時不影響 `backups/` 與 `.api-key`，若有自訂詞條請先備份。
- **完整移除**：執行選項 `2` 還原英文原版後，直接刪除本資料夾即可。
