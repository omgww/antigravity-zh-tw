# Antigravity 繁體中文語系包

將 Antigravity 介面轉為繁體中文。支援 Windows 10 / 11，不需額外安裝環境，目前內建字典對應版本為 `v2.31.2`（共 2,040 條詞條）。

## 1. 下載與安裝

1. 點選右上角 `Code` → `Download ZIP`，解壓縮至個人使用者目錄下的固定資料夾（若搬移位置，請於新位置重新執行選單 `1` ）。
2. 雙擊 `Antigravity-zhTW.cmd`（若跳出 Windows 保護視窗，點選「其他資訊」→「仍要執行」）。
3. 輸入數字 `1`～`4` 執行對應操作：
   - `1` 套用或修復繁體中文化：將介面轉為繁體中文。
   - `2` 還原為官方英文原版：恢復英文介面。
   - `3` 掃描未翻譯詞條與檢查字典：比對軟體內尚未翻譯的英文詞條，並檢查 `zh-tw.json` 是否有重複項目。
   - `4` 設定新詞條自動翻譯模式：預設關閉。開啟後，版本更新或執行選單 `3` 時會自動補齊新增詞條並寫入 `zh-tw.json` 底部的 `"auto"` 區段。

## 2. 日常更新與異常提示

- 軟體內更新重啟：在已中文化的狀態下點選軟體內的更新重啟，安裝完畢後會自動切換並補回繁體中文。
- 關閉軟體自動更新：新版於背景下載完畢後關閉視窗時，安裝結束後會於背景自動補回繁體中文，下次開啟直接維持繁中介面。
- 手動覆蓋安裝：若自行從官網下載安裝包覆蓋安裝，完成後執行一次 `Antigravity-zhTW.cmd` 選單 `1` 即可補回。

## 3. 快捷鍵與修改翻譯

- `Alt + Z`：於繁體中文與英文原文之間切換。
- 修改翻譯：直接用文字編輯器修改 `zh-tw.json` 並存檔，已開啟的視窗會立即套用。

## 4. 使用其他字典檔

1. 直接替換：將其他 JSON 字典檔重新命名為 `zh-tw.json`，覆蓋本資料夾內的同名檔案即可生效。
2. 合併詞條：將其他字典檔內的 `"英文": "中文"` 詞條複製貼入 `zh-tw.json` 任一區塊後存檔，再執行選單 `3` 檢查是否有重複詞條。

## 5. 完整移除

雙擊 `Antigravity-zhTW.cmd` 輸入 `2` 還原英文原版後，直接刪除本資料夾即可。
